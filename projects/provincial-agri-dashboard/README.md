# Project 7: Provincial Agricultural Economic Dashboard

## Overview
An interactive dashboard analysing agricultural economic perfomance across all 9 South African provinces uing official govwernment data  from DALRRD (2022-2024)

## Problem Statement
Provincial agricultural economic data in South Africa is often locked in static government reports, making it difficult for extension officers, policymakers and agribusinesses to quickly identify which provinces aregrowing, which commodities dominate, and where investment is needed most.

## Objective
Transform raw provincial agricultural statistics into a clean, interactive dashboard that answers:
- Which province contributes most to agricultural GDP?
- Which commodities dominate per province?
- How has provincial output trended over 3 years (2022-2024)?
- Which provinces are growing vs declining?
   
## Tools & Technologies
|Layer | Tool |
|------|------|
|Data Extraction | Excel ( Power Query)|
|Cleaning & Analysis | Excel|
|Visualisation | Looker Studio |

## Dataset
- **Source:** DALRRD Abstract of Agricultural statistics 2022, 2023, 2024
- **Coverage:** All 9 South Africn provinces
- **Variables:** Crop production, Livestock, Horticulture agricultural GDP contribution
